## DARPA Phased Project Template

### Phase Structure

| Phase | Duration | Focus | Go/No-Go Criteria |
|-------|----------|-------|-------------------|
| Phase 1 | 12-18 months | Feasibility | Technical feasibility demonstrated |
| Phase 2 | 18-24 months | Development | Prototype meets performance targets |
| Phase 3 | 12+ months | Demonstration | System demonstrated in operational environment |

## Generating Visual Gantt Charts

To generate professional Gantt charts, use the `scientific-schematics` skill:

```bash
python scripts/generate_schematic.py "Gantt chart for 3-year research project with 3 aims: Aim 1 (blue) runs Y1Q1-Y2Q2, Aim 2 (green) runs Y1Q3-Y3Q1, Aim 3 (orange) runs Y2Q4-Y3Q4. Milestones at Y1Q4, Y2Q3, Y3Q4." -o figures/gantt_chart.png
```

This will create a publication-quality Gantt chart image suitable for inclusion in your proposal.
