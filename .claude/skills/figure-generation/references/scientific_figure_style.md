# Scientific Figure Visual Style Specification

**This is the SINGLE SOURCE OF TRUTH for all figure styles in this project.**

Every figure — whether rendered by matplotlib or generated by AI — MUST follow this specification. Read this file before creating ANY figure.

---

## Color Palette

Use the **Okabe-Ito** colorblind-safe palette. Apply colors in this order for categories/series:

| Order | Hex | Name |
|-------|-----|------|
| 1 | `#E69F00` | Orange |
| 2 | `#56B4E9` | Sky Blue |
| 3 | `#009E73` | Bluish Green |
| 4 | `#0072B2` | Blue |
| 5 | `#D55E00` | Vermillion |
| 6 | `#CC79A7` | Reddish Purple |
| 7 | `#F0E444` | Yellow |
| 8 | `#000000` | Black (fallback) |

**Rules:**
- Always use this palette for data series, categories, and groupings
- For heatmaps: use `viridis` colormap
- For single-series figures: use color #1 (orange) as default
- For diverging data: use blue (`#0072B2`) to vermillion (`#D55E00`)

## Typography

| Element | Font | Size | Weight |
|---------|------|------|--------|
| Axis labels | Arial / Helvetica | 9pt | Regular |
| Figure title | Arial / Helvetica | 10pt | Bold |
| Tick labels | Arial / Helvetica | 8pt | Regular |
| Legend text | Arial / Helvetica | 8pt | Regular |
| Annotations | Arial / Helvetica | 8pt | Regular |

**Rules:**
- **Sans-serif only** — Arial preferred, Helvetica as fallback, DejaVu Sans as last resort
- **Never use serif fonts** (Times New Roman, etc.) in figures
- Body text of the paper may use Times New Roman, but ALL figures use sans-serif
- In AI-generated images: render all text in Arial/Helvetica style

---

## Axes and Borders

- **Remove top and right spines** (borders) — "despined" style
- **Keep bottom and left spines** at 0.5pt line width
- **Tick direction:** outward
- **Major tick size:** 3pt, **width:** 0.5pt
- **Minor tick size:** 1.5pt, **width:** 0.5pt
- **Tick padding:** 3pt
- **Axis label padding:** 4pt
- **Title padding:** 6pt

---

## Lines and Markers

| Element | Width/Size |
|---------|-----------|
| Axis spines | 0.5pt |
| Data lines | 1.0–1.5pt |
| Grid lines | 0.3pt (when needed) |
| Marker size | 4pt (filled) |
| Patch outlines | 0.5pt |

---

## Layout

- **Background:** white, no gradients
- **Grid:** off by default; if essential, use 0.3pt at 70% opacity
- **Legend:** no frame/border, handle length 1.5
- **No drop shadows**, no 3D effects, no decorative elements
- **No chartjunk** — maximize data-ink ratio (Tufte principle)

## AI Image Generation Directives

When generating figures via AI (scientific-schematics, generate-image), include these directives in the prompt:

```
VISUAL STYLE (mandatory):
- Color palette: Okabe-Ito colorblind-safe — use these hex colors in order:
  #E69F00, #56B4E9, #009E73, #0072B2, #D55E00, #CC79A7, #F0E444
- Font: Arial or Helvetica (sans-serif only), no serif fonts
- Font sizes: 8-9pt for labels, 10pt bold for titles
- Axes/borders: show only bottom and left, no top/right border
- Line width: 0.5pt for structure, 1.0pt for data/connections
- Background: solid white, no gradients or textures
- No drop shadows, no 3D effects, no decorative elements
- Clean, minimal, publication-ready aesthetic
- White space: adequate margins, not cramped
```

---

## General Principles

1. **Consistency** — ALL figures in the same document must use the same style
2. **Clarity** — reader should understand the figure without reading the caption
3. **Simplicity** — remove everything that doesn't convey information
4. **Accessibility** — Okabe-Ito palette works for colorblind readers
5. **Editability** — PDF output with TrueType fonts (fonttype=42) for Illustrator editing
