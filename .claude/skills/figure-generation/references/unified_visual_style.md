# Unified Scientific Visualization Style Guide

**This is the SINGLE CANONICAL STYLE for ALL scientific visualizations in this project.**

Every figure -- whether rendered by matplotlib, generated by AI (scientific-schematics, generate-image), used in infographics, posters, or slides -- MUST follow this specification. Read this file before creating ANY visual element.

---

## Color Palette -- Okabe-Ito (Colorblind-safe)

| Role | Color | Hex |
|------|-------|-----|
| Primary 1 (default) | Orange | #E69F00 |
| Primary 2 | Sky Blue | #56B4E9 |
| Primary 3 | Bluish Green | #009E73 |
| Primary 4 | Yellow | #F0E442 |
| Primary 5 | Blue | #0072B2 |
| Primary 6 | Vermillion | #D55E00 |
| Primary 7 | Reddish Purple | #CC79A7 |
| Neutral | Black | #000000 |
| Background | White | #FFFFFF |
| Grid | Light Gray | #E0E0E0 |

**Usage rules:**
- Assign colors in order (Primary 1 first) for sequential data series
- For heatmaps: use `viridis` colormap
- For single-series figures: use Primary 1 (Orange) as default
- For diverging data: use Blue (#0072B2) to Vermillion (#D55E00)

## Typography

| Element | Font | Size | Weight |
|---------|------|------|--------|
| Figure title | Arial | 14pt | Bold |
| Axis labels | Arial | 12pt | Normal |
| Tick labels | Arial | 10pt | Normal |
| Legend text | Arial | 10pt | Normal |
| Annotation | Arial | 9pt | Italic |
| Panel label (a,b,c) | Arial | 12pt | Bold |

Fallback: DejaVu Sans (if Arial unavailable)

**Rules:**
- Sans-serif only -- Arial preferred, Helvetica as fallback, DejaVu Sans as last resort
- Never use serif fonts (Times New Roman, etc.) in figures
- Body text of the paper may use Times New Roman, but ALL figures use sans-serif

---

## Axes & Layout

- **Spines:** top=False, right=False (despined)
- **Spine linewidth:** 1.2pt
- **Tick direction:** out
- **Grid:** y-axis only, alpha=0.3, dashed
- **Tight layout** with 0.5cm padding
- **Panel labels:** upper-left corner, "(a)", "(b)", etc.

## AI-Generated Diagrams

When generating figures via AI (scientific-schematics, generate-image, infographics), include these directives in every prompt:

```
VISUAL STYLE (mandatory):
- Color palette: Okabe-Ito colorblind-safe -- use these hex colors:
  #E69F00, #56B4E9, #009E73, #F0E442, #0072B2, #D55E00, #CC79A7
- Font: Arial or Helvetica (sans-serif only), no serif fonts
- White background, no decorative borders
- Consistent line weights: 2pt for main flow, 1pt for secondary
- No drop shadows, no 3D effects, no decorative elements
- Clean, minimal, publication-ready aesthetic
```

---

## Data Chart Specifics

| Chart Type | Specification |
|------------|---------------|
| Bar charts | No 3D, no gradient fills, edgecolor=white linewidth=0.5 |
| Scatter | Marker size 30-60, alpha=0.7, edgecolor=white |
| Line | linewidth=2.0, marker='o' at data points |
| Heatmap | viridis or Okabe-Ito sequential, annotated values |
| Box/whisker | notch=True, showfliers=True, whisker=1.5*IQR |

---

## General Principles

1. **Consistency** -- ALL visual elements in the same document must use this style
2. **Clarity** -- reader should understand the figure without reading the caption
3. **Simplicity** -- remove everything that doesn't convey information
4. **Accessibility** -- Okabe-Ito palette works for colorblind readers
5. **Editability** -- PDF output with TrueType fonts (fonttype=42) for Illustrator editing
