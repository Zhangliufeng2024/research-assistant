# 前端交互方案（阶段 4 设计定稿）

> 参照对象：WorkBuddy / Claude（Cowork 模式）/ Codex App 三者的共性布局语言。
> 定稿日期：2026-08-29。本文是阶段 4（U-3~U-11）的实施依据，先定方案再动代码。

## 1. 布局：三栏 + 可折叠左栏（对齐 Cowork / Codex App）

```
┌──────────┬──────────────────────────────┬────────────┐
│ 导航栏    │  会话区（常驻）                │  检查器     │
│ 64px     │  对话流 + 输入框               │  (按需)     │
│          │                              │            │
│ ⌂ 项目    │  ┌──────────────────────┐    │ 变更/产物   │
│ 💬 会话   │  │ 消息流（虚拟滚动）      │    │ 任务详情    │
│ 📁 产物   │  │ …                    │    │ 预算/用量   │
│ 🕘 历史   │  └──────────────────────┘    │            │
│ ⚙ 设置    │  [输入框 + 工具条]             │            │
└──────────┴──────────────────────────────┴────────────┘
```

- **导航栏（窄，图标+短标签）**：项目 / 会话 / 产物 / 历史 / 设置。
  会话列表是导航栏的**二级抽屉**（点开滑出，不占常驻栏位）——对齐 Codex App
  的"任务列表按需展开"，避免 WorkBuddy 式三栏全展开在窄屏挤压会话区。
- **会话区常驻（U-4 核心）**：切换会话/查看产物/改设置，会话区**不卸载**。
  现状是路由切换即卸载、重进丢失滚动位置与输入草稿。改为会话区是
  `App` 布局的常驻子树，导航只切换它的**伴生面板**。
- **检查器（右侧，按需）**：产物预览 / 变更 diff / 任务运行详情 / 预算用量。
  宽屏 ≥1280px 可常驻；<1280px 变为滑出抽屉（U-11 窄屏兜底：任何面板
  在窄屏都有抽屉形态，不消失）。

## 2. 会话区常驻的状态保持

- 每会话一个 `SessionStore`（zustand）：`draft`（输入草稿）、`scrollAnchor`、
  `pendingAttachments`、`streamingState`。切换会话 = 切换 store 实例，
  组件树不重挂（React key 用会话 id，但会话区壳层 key 固定）。
- 路由层面：`/project/:id/session/:sid` 只控制检查器内容与 URL 同步，
  会话区壳层不参与路由卸载。
- 离开会话时草稿自动持久化到 localStorage（按 sid 键），崩溃恢复可用。

## 3. 快捷键体系（对齐 Claude / Codex，全部可自定义存储于设置）

| 快捷键 | 动作 | 参照 |
|---|---|---|
| `Ctrl/Cmd+K` | 命令面板（跳转会话/产物/执行任意命令） | WorkBuddy/Codex |
| `Ctrl/Cmd+Enter` | 发送消息 | 通用 |
| `Ctrl/Cmd+Shift+O` | 新建会话 | ChatGPT/Claude |
| `Ctrl/Cmd+B` | 折叠/展开左栏导航 | Codex/VSCode |
| `Ctrl/Cmd+I` | 检查器开关 | Cowork |
| `Ctrl/Cmd+.` | 中断当前回合（停止生成） | Claude |
| `Ctrl/Cmd+J` | 聚焦输入框（从任意面板） | 通用 |
| `Esc` | 关闭抽屉/命令面板/取消聚焦 | 通用 |
| `Alt+↑/↓` | 在会话列表中上下切换 | Codex |
| `Ctrl/Cmd+,` | 打开设置 | 通用 |

实现：单一 `useHotkeys` 中心注册表（`src/hooks/useHotkeys.ts`），
命令面板与快捷键共享同一命令注册表（`registry: {id, title, run, hotkey}`），
避免两套分发。输入框聚焦时仅 `Esc`/发送类快捷键生效（不劫持打字）。

## 4. 命令面板（新增，低成本高收益）

`Ctrl/Cmd+K` 打开；数据源 = 会话列表 + 产物 + 命令注册表。
模糊匹配用现有依赖（若无则引入 `fuse.js`，~6KB）。这是把"会话多了找不到"
的痛点和快捷键体系一次解决的最小载体。

## 5. 实施切分（对应 U 项）

1. **U-4 常驻会话区**：App 布局改造 + SessionStore（1 天）
2. **U-3 项目层**：导航栏 + 会话二级抽屉（1 天，依赖 1 的布局壳）
3. **命令面板 + 快捷键**：注册表 + useHotkeys + 面板 UI（1 天）
4. **U-11 窄屏兜底**：检查器/导航抽屉化（0.5 天）
5. **8 条关键链路测试**：发送/中断/重连续播/审批/归档/编辑重发/切换会话/
   切换工作区（1.5 天，DOM 测试基础设施已就绪）

## 6. 明确不做的

- 多会话分屏（Codex 有，本项目场景收益低，复杂度高）；
- 拖拽自定义布局（用固定三档响应式断点替代）；
- 移动端原生适配（抽屉兜底已覆盖窄屏，原生另行立项）。
