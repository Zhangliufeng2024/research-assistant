## 1. 采集方式

```bash
# 后端（覆盖率刻意不进 addopts，未安装 pytest-cov 的环境仍可跑测试）
PYTHONPATH= .venv/Scripts/python.exe -m pytest -p no:cacheprovider \
  --basetemp=.pytest_tmp_base -q \
  --cov=research_assistant --cov-report=term --cov-report=xml

# 前端
cd frontend && npx vitest run --coverage     # 仅 report，尚未设阈值
```

> **本沙箱的两个已知限制**（与项目代码无关，详见 `.workbuddy/memory`）：
> - 全量 `vitest run` 会挂起 → 按目录跑（`src/lib`、`src/stores`、`src/hooks`、`src/components`、`src/views`）
> - 前端覆盖率报告生成会被环境的 safe-delete shim 拦截（coverage 目录清理）→ **前端覆盖率数字由 CI 采集**
