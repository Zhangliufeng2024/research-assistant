# 使用说明 · Research Assistant 桌面版

> 适用于打包版桌面应用（ResearchAssistant.exe / 安装包）。本应用是 AI 驱动的
> 科研与写作助手：既能深度检索、也能直接产出可发表的文档（Word/PDF）、临摹图、
> 数据图与示意图，并管理研究工作台（研究问题/主张/证据/可复现运行/审批）。
>
> - 运行平台：Windows（pywebview / WebView2 单窗口桌面应用）
> - 彻底离线本地运行：模型通过你的 API Key 调用云端或自建端点，应用本体局域网只绑定 127.0.0.1。

## 1. 安装与启动

### 1.1 安装包方式（推荐）

双击 `ResearchAssistant_setup_<版本>.exe`，按提示安装。安装完成后在开始菜单
找到 **Research Assistant** 启动。

- 安装**无需单独安装 Python**（已把解释器与依赖打包进 exe）；
- 若系统缺少 WebView2 运行时，首次启动会给出图形化指引。

### 1.2 免安装方式（可选）

解压后的 `dist/ResearchAssistant/` 目录里双击 `ResearchAssistant.exe` 同样可运行，
程序会直接使用该目录就近启动，不注册系统安装项。

## 3. 界面总览

桌面窗口为单窗口应用，左侧功能导航、主区内容。点亮的功能页包括：

| 页面 | 用途 |
|---|---|
| **项目首页** | 实验室总览：研究线程、任务、质量项、产物、决策、用量汇总 |
| **会话** | 通用 AI 会话工作台（流式对话、工具卡、审批、附件） |
| **任务** | 论文/文档生成任务、运行历史、后台任务、DAG 节点、指标 |
| **研究工作台** | 研究线程、假设、主张、证据矩阵、决策 |
| **来源 / 资料库** | 导入 PDF/DOCX/MD/TXT/BibTeX，检索（关键词/语义/混合） |
| **分析运行** | 可复现数据分析运行、比较、复现 |
| **调度** | 持久化作业队列 / 资源租约 / 定时触发器 |
| **论文库** | 已生成论文/文档（zip 导出） |
| **变更** | 产物版本 diff 与一键恢复 |
| **审批** | 待处理工具调用审批收件箱 |
| **审阅** | 产物审阅闭环（预览/diff/要求修改） |
| **通知** | 系统通知中心 |
| **设置** | 模型配置、工作区、外观（浅/深主题） |

其中**会话**和**任务**是最常用的两条主线（见下几节）。

## 4. 快速上手：跑通第一轮对话

1. 在「会话」页右侧输入一句话，例如：*“分析这个 CSV 的列分布并画一张直方图”*；
2. 消息发出后进入「运行中」，底部打出活动时间线与 LLM 输出流；
3. 助手会先调用工具（读文件/跑 Python/画图/检索），以**工具卡**展示进度；
4. 流式文本逐段上屏；随时可在输入框输入 **steer（转向指令）** 让助手中途改方向；
5. 若触发危险工具，会弹**审批卡**，点「允许 / 拒绝」；
6. 完成后，右侧**产出 dock** 立即显示本会话生成的产物，可点开预览或「打开文件夹」。

> 断网 / 切走页面的对话不中断：回合由服务端继续跑完并落盘，重连后自动补齐错过的输出。

### 1.3 工作区

首次启动会自动创建一个工作区（默认在「文档 / 研究助手」），这是你所有研究、
产物的存放地。**换工作区**在「会话」页的工作目录入口或设置页完成；工作区记忆
保存在 `%APPDATA%\ResearchAssistant\desktop.json`。

> 提示：工作区建议视为「项目根」，不同研究项目建不同工作区，互不干扰。

## 2. 首次配置（接入模型）

首次打开在**设置页**完成模型接入。全局配置写在
`%APPDATA%\ResearchAssistant\.env`，所有工作区共享一份，改完即时生效。

### 2.1 对话/写作模型（必填）

| 配置 | 说明 |
|---|---|
| API Key | 必填。`sk-ant-*` 开头自动识别为 Anthropic；否则按 OpenAI 兼容处理 |
| Provider | `anthropic` / `openai`（留空由 Key 格式自动判断） |
| Base URL | 留空用各厂商默认；自建网关/代理时填你的端点 |
| Model | 模型名（Anthropic 默认 `claude-sonnet-5`；OpenAI 兼容默认 `gpt-4o`） |

### 2.2 图片生成模型（可选，独立）

画示意图 / 数据图 / AI 配图时用到，与写作模型完全解耦：

| 配置 | 说明 |
|---|---|
| IMAGE_API_KEY | `nvapi-` 开头 → 走 NVIDIA NIM；否则走 OpenAI 兼容图片端点 |
| IMAGE_BASE_URL | 默认 `https://apihub.agnes-ai.com/v1` |
| IMAGE_MODEL | 默认 `agnes-image-2.0-flash` |

> 记法：写作与图像是两套独立 Key，即使同一厂商也请分开配置。

### 2.3 全局 vs 工作区

- 全局 `.env`：设置页托管的 4 个键（`LLM_API_KEY/LLM_BASE_URL/LLM_MODEL/LLM_PROVIDER`），跨工作区共享；
- 其余（图像 Key、预算、超时等）读环境变量或全局配置；老版本用户首次打开设置页会自动把旧配置上移为全局。

## 5. 会话工作台

### 5.1 会话列表
- 左侧会话可**新建 / 重命名 / 删除**；
- 空会话（零轮次）会自动清退，不留残骸；
- 会话**持久化**：重启后从 `history.json` 恢复全部往来。

### 5.2 输入与附件
- 支持**附件**：点 📎、拖拽或粘贴文件，单条 ≤8 个、总量 ≤50MB；
- 附件随消息入史，刷新后徽章仍在；模型可读取/写入本会话 `outputs/<会话ID>/uploads/`。

### 5.3 真·重新生成 / 编辑重发
- 「重新生成」：服务端把该问题之后的旧回答**真正删除**，再以原文重发；
- 「编辑重发」：改文字后再删重发，不产生空转的平行答案。

### 5.4 审批
- 危险 / 需确认操作弹出审批卡；120 秒无响应自动拒绝；过期回执不计入下一次审批。

## 6. 桌面任务 / 研究工作台

### 6.1 论文 / 文档任务
输入研究问题 → 选择**工作流**（论文流水线 / 研究问题冲刺 / 可复现数据分析）→ 起跑：
- 任务页实时展示 **DAG 节点**（规划→研究∥→图表∥→组装→质量门→修订→定稿）状态与耗时；
- 关键路径 / 节点指标、预算（金额 / 词数 / 轮次 / 时长）实时可见；
- 产出在 `writing_outputs/<时间戳>_<描述>/`（drafts/ final/ references/ figures/ data/ sources/）。

### 6.2 后台任务
- 运行中的任务即使**断开连接**也照常跑完（后台任务 hub，SQLite 持久化）；
- 断线回放事件（observe 协议），任务页可继续观察或一键续跑（interrupted 任务可重跑）。

### 6.3 质量门（Gates）
- 定稿前必经 CitationGate（引用真实可查）与 DocGate（章节齐 / 图在 / 无占位 / 字数达标）；
- 不通过会计入有界修订（≤3 轮），生成 gate 报告注入；通过后才写 `final/`。

## 7. 论文与文档生成流水线

1. 在「任务」页输入主题（如“桥梁加固的 LCA 综述”），选「论文流水线」；
2. 规划器拆章（要点/字数）→ 并发调研 + 出图 → 组装成 Word 草稿；
---

## 9. 资料库 / 来源检索

- 支持导入：PDF、DOCX、Markdown、TXT、BibTeX；
- 检索三种模式：**关键词 / 语义 / 混合**（离线可跑，不依赖外部向量服务）；
- 结果回到文档 / 片段 / 页码 / 哈希锚点，审阅时可定位原文。

---

## 10. 产物与恢复（变更 / 审批 / 通知）

- **产物版本化**：agent 每次写 / 编辑文件都留版本快照，**变更页**可一键恢复历史版本；
- **审阅闭环**：产物自动索引真实输出文件（相对路径 / 版本 / SHA-256 / 类型 + 质量门摘要），可对其「要求修改」并写回线程与通知；
- **审批收件箱**：持久化，可展示 Agent / 角色，带一次性 request_id、防迟到回执；
- **通知中心**：统一查看。

---

## 11. 工作区与文件管理

- 「会话」页或设置页可**切换工作目录**（启动器也支持 `research-assistant-desktop [目录]`）；
- 文件树懒加载：`.git/__pycache__/.ra/node_modules/隐藏文件` 自动忽略；
- 越界（符号链接等 / 围栏）一律拒绝，安全基线不放宽。

## 12. 常用环境变量与目录

### 12.1 主要运行目录

| 项 | 路径 |
|---|---|
| 全局配置 | `%APPDATA%\ResearchAssistant\.env` |
| 工作区记忆 | `%APPDATA%\ResearchAssistant\desktop.json` |
| 桌面日志 | `<工作区>\.ra\logs\desktop.log`（滚动 1MB×3） |
| 会话历史 | `<工作区>\.ra\sessions\<会话ID>\history.json`（唯一权威） |
| 会话产物 | `<工作区>\outputs\<会话ID>\`（上传 / 画图 / 脚本产物） |
| 库审计 | 事件 `events.jsonl`、运行 `run.json` |

### 12.2 常用环境变量（可写入全局 .env）

| 变量 | 默认 | 说明 |
|---|---|---|
| `RA_MAX_*`（COST_USD / TOKENS / TURNS / WALL_SECONDS） | 无限 | 单次运行预算硬上限，超限优雅停止 |
| `RA_CHAT_ORPHAN_GRACE_SECONDS` | 900 | 断线且无观察者后，回合保留再收的宽限（秒） |
| `RA_LLM_FIRST_BYTE_TIMEOUT` | 常量 | 流式首字节静默窗口（短超时快失败） |
| `RA_LLM_ATTEMPT_WALL_TIMEOUT` | 常量 | 单次 LLM 调用墙钟上限 |
| `RA_MAX_RETRIES` / `RA_RETRY_BASE_DELAY` | 3 / 5.0 | 网络类错误重试次数与退避基数 |
| `RA_MULTI_AGENT` | off | 多代理流水线开关 |

其余预算 / 重试 / 守卫的完整清单见 `docs/protocol.md`。

## 13. 日志与排障

- 桌面日志：见 12.1（`desktop.log`，滚动 1MB×3）。
- 常见问题：
  - **启动无窗口**：检查是否安装 WebView2 运行时；
  - **模型无法连接**：确认设置页已填 Provider / Base URL / Key；自建网关注意网络可达；
  - **图像一直失败**：`IMAGE_API_KEY / IMAGE_BASE_URL / IMAGE_MODEL` 需与厂商匹配；
  - **bash 里 `python` 报指引**：打包版没有独立 python，绘图 / 跑脚本走内置 `run_python`
    （已含 numpy/pandas/matplotlib）与 `run_script`，属预期行为而非故障。

## 14. 安全与隐私说明

- 仅监听 `127.0.0.1` 随机端口，不对外网暴露；
- 密钥走 GUI 配置写入 `%APPDATA%`，不进源码树；打包前后各做一次全仓泄漏扫描，
  发现疑似 Key 会中止发布；
- 资料库 / 研究包导出剔除 `.env`、`.ra`、VCS 与缓存；
- 写盘受 `write_anchor` 与 `safe_resolve` 围栏约束，越界一律拒绝。

## 术语对照

- **回合（Turn）**：一次「用户消息 → 助手完整回复全路径」。
- **帧（Frame）**：回合内服务端推送的消息单元（文本增量 / 工具卡 / 审批 / usage / 结果），带递增序号。
- **环形缓冲**：断线后保留最近 4000 帧，重连按 `after` 游标补播；超限仅丢最新 usage 快照（不影响语义）。
3. 审阅 agent 校验内容与引用，产出 `PEER_REVIEW.md` 与最终 `final/manuscript.docx`（可选 PDF）；
4. 论文与图表都在**产物库**可溯源，支持打包 zip 导出。

> 支持多智能体并行；引用查询多家学术库，**不编造文献**——引用未通过验证会阻止定稿而非写出假参考文献。

## 8. 研究工作台（科研 OS）

- **研究线程**：研究问题 / 假设的持久化记录；
- **主张 + 证据**：证据矩阵，主张 ↔ 证据 ↔ 来源 可溯源（来源含页码 / 片段 / 哈希锚点）；
- **决策**：记录研究决策与依据；
- **可复现运行**：`RA_ANALYSIS_*_JSON` 环境契约脚本以独立分析运行保存输入 / 输出；
- **研究包**：`/api/project/export` / `import` 安全打包研究图谱、任务、运行、审阅、质量与通知（剔除 `.env`、`.ra`、VCS、缓存）。
